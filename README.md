# AI-BASED-SIGN-LANGUAGE-DETECTION
sign language detection using yolov5 and deep learning## Overview
This project detects sign language gestures using Computer Vision and Deep Learning techniques with YOLOv5.

## Technologies Used
- Python
- YOLOv5
- OpenCV
- PyTorch
- Google Colab

## Features
- Object detection based sign recognition
- Custom dataset training
- Model evaluation using IoU and confidence score
- Real-time deployment scope

## Future Scope
- Webcam-based real-time detection
- Embedded AI deployment
